# Task 6 — Buffered file copy

Compile on Linux: `gcc -std=c11 -Wall -Wextra -pthread copy_file.c -o copy_file`.

Run from this folder. The test creates 10,000 bytes, copies with buffer sizes 1, 512, and 4096, prints read-call counts (including the EOF read), and removes both files. Expected counts: 10001, 21, 4. The local MSYS2 run matched all three. Linux strace and time evidence are generated by `../scripts/run_linux_evidence.sh` on Ubuntu CI.
